# P2.6 — Blended MER Dashboard Plan

> REQUIRED SUB-SKILL: superpowers:executing-plans.

**Goal:** Compute + visualize blended MER (revenue / ad spend) from the seeded ClickHouse `ad_performance` data, with a 30/60/90-day trend + channel breakdown.

**Senior decisions (locked):**
- **API queries the seeded ClickHouse** (`@clickhouse/client`) — validates the P2.1 seed end-to-end. `ensureAdPerformanceSeed(ws)` inserts seeded rows per workspace if empty (mirrors `ensureRecommendations`), then aggregates.
- Revenue = seeded `conversion_value × 2.2` (blended stand-in). **Real Shopify pull + manual revenue entry → M3.**
- MER via the canonical `@growthos/logic` `calculateBlendedMER`.
- Anomaly (>15% WoW) computed + flagged in the response; the **WebSocket `analytics:mer_alert` → P2.7**.
- Requires ClickHouse running (`docker compose up -d`) — already the M2 dev requirement.

### Task 1: API — ClickHouse client + MER trend
- `apps/api/src/analytics.ts` (+ test): `getClickhouse()` (singleton, `CLICKHOUSE_URL` default `http://localhost:8123`); `ensureAdPerformanceSeed(ws)` (insert 30d google+meta rows if none); `getMerTrend(ws, days): { trend: {date, mer, spend, revenue}[], summary: MERResult, channelBreakdown, anomaly }` (aggregate by date, `calculateBlendedMER` per day). Route `GET /workspaces/:id/analytics/mer?days=30|60|90`. TDD (integration vs local ClickHouse) → typecheck → test → commit.

### Task 2: types
- `MerTrendPoint`, `MerDashboard` in `@growthos/types`. Build → commit.

### Task 3: Frontend — MER dashboard (Recharts)
- `pnpm --filter @growthos/web add recharts`; `apps/web/lib/hooks/useMer.ts` (live only — no fixture ClickHouse; on fail returns a small computed mock trend); MER dashboard page `app/(dashboard)/analytics/page.tsx` (summary MER card + 30/60/90 toggle + Recharts area/line trend + channel breakdown, theme tokens `--primary`/`--success`); Sidebar nav ("Analytics"). Build → commit.

### Task 4: E2E + trackers
- `apps/api/scripts/e2e-mer.ts` (ensure seed + trend length + summary); `progress.md`; roll up. Commit.
