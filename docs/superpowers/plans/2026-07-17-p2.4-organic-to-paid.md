# P2.4 — Organic-to-Paid Bridge Plan

> REQUIRED SUB-SKILL: superpowers:executing-plans. Mirrors P2.3b for the `organic_to_paid` type.

**Goal:** Surface top organic pages as Meta creative opportunities — generate `organic_to_paid` recs + Meta **creative briefs**, shown on a Creative Queue page with act/dismiss/snooze.

**Senior decisions (locked):**
- The cross-channel engine already encodes the `SEO→Meta` (organic→paid) and `Meta→SEO` (CTR>3% reverse loop) rules. P2.4 productizes the organic→paid side with a dedicated type + Meta creative briefs (mirror of P2.3b's paid→organic).

- Logic in `@growthos/logic`, scoring synchronous in the API (no Python worker) — consistent with P2.3.
