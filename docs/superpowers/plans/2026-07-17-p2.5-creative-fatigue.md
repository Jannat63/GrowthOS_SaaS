**Goal:** Detect fatiguing Meta creatives and surface refresh recommendations on a Fatigue Monitor page with act/dismiss/snooze.

**Senior decisions (locked):**
- Fatigue detection runs **synchronously in the API** over seeded creatives via `@growthos/logic` (`detectFatigueAll`). The **scheduled 4-hourly worker + `meta_ad_sets` table → M3** (real data + scheduling).
- **Resend email → M5** (lifecycle emails; needs account). **WebSocket `meta:fatigue_alert` → P2.7** (notification center).
- No brief table — the refresh suggestion lives in the recommendation body. Type `fatigue_alert`, source/target `meta_ads`.
- Alert on `status !== 'healthy'` (fatigued or at-risk).
